# 佐藤輝明｜三冠王への道 — 公開終了

2026年11月3日、所有者の依頼により公開と運用を終了しました。

- 公開先のサイト本体・成績データ・画像・サイトマップを撤去しました。旧URLは終了案内を表示する404応答の構成です。
- 定期取得・自動公開のワークフローと、今回限りの撤去ワークフローを `archive/` に退避しました。`.github/workflows/` に有効な処理は残していません。
- `dist/`、取得済みデータ、ソースコード、Gitの履歴は復元用に保持しています。リポジトリ自体は削除していません。
- GitHub Pagesの設定は保持していますが、配信物は終了案内用の `404.html` と `.nojekyll` だけです。サイト本体の配信・自動更新は行いません。
- エールの共有APIは未設定（`endpoint: null`）で、今回停止する外部集計サービスはありません。
